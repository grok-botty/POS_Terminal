Обзор продукта
==============

CashMachine — рабочее место кассира кофейни. Всё стоит и работает локально
на ноутбуке или мини-ПК за кассой: Django-приложение поднимает SQLite,
рендерит HTMX-интерфейс в браузере (или в окне pywebview на Windows) и не
требует внешнего сервера.

Ключевые сценарии
-----------------

* **Оформление заказа.** Кассир выбирает категорию, товар, при необходимости
  выставляет модификаторы (сироп, молоко), указывает имя гостя, комментарий
  и формат — «В зале» или «С собой», — затем нажимает «Оплачено».
* **Выдача.** На экране «Выдача» бариста видит все оплаченные заказы,
  сортированные по времени оплаты. Кнопка «Все готовы» одним кликом
  переводит все активные заказы в статус «Готов»; кассир нажимает «Отдан»
  когда гость забирает заказ.
* **Меню.** Менеджер (`admin`) редактирует категории, товары, группы
  модификаторов и опции. Меню применяется мгновенно: следующий заказ уже
  видит изменения.
* **Аналитика.** Отдельный экран показывает выручку по дням, топ товаров,
  загрузку по часам и историю закрытых смен.
* **Закрытие дня.** Один клик на «Закрыть день» фиксирует смену в
  :class:`apps.analytics.models.DailySummary` — далее эти данные попадают в
  графики и остаются неизменными, даже если задним числом исправляют
  отдельные заказы.

Роли
----

* ``admin`` — полный доступ: касса, выдача, меню, аналитика, Django-админка.
* ``cashier`` — касса + выдача + закрытие смены.

UX-принципы
-----------

* Никаких лишних кликов: товар без модификаторов добавляется в заказ ровно
  одним нажатием.
* Активная строка в панели заказа подсвечивается для страховки от
  «случайного минуса».
* Формат «В зале / С собой» — крупные чипы вместо выпадающего списка.
* Экран выдачи автоматически обновляется каждые 5 секунд через HTMX polling,
  чтобы бариста и кассир видели одинаковую очередь.

Технологический стек
--------------------

* **Backend:** Python 3.10+, Django 5.x, SQLite, django-htmx, WhiteNoise.
* **Frontend:** серверный рендер + HTMX для интерактивности + Alpine.js
  (18 KiB, только для мелких клиентских тумблеров).
* **Desktop:** pywebview (окно) + PyInstaller (сборка одного `.exe`).
* **Docs:** Sphinx с темой Furo, автогенерация из docstring через
  ``sphinx.ext.autodoc``.
